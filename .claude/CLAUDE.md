# Code Conventions

Shared ESLint, Prettier, and Ember linting configurations for all abofs projects. Published to npm as `@abofs/code-conventions`.

## Documentation

See [`docs/index.md`](../docs/index.md) for the full documentation index.

## Quick Reference

- **Package:** `@abofs/code-conventions`
- **Exports:** `./eslint`, `./eslint-ember`, `./prettier`, `./template-lint`, `./lint-staged`
- **CLI:** `code-conventions-setup` (husky pre-commit setup)
- **Test:** `pnpm test` (eslint + prettier self-check)
- **Release:** `docs/release.md`
